## Framework Modifications

- An issue that the game may stutter while initiating cross-zone navigation for the first time has been fixed.
- The context synchronization while enabling and disabling Daily Routines has been improved.
- An issue that exceptions occurred during module enabling and disabling may leak into an unmanaged layer has been fixed.
- Periodic update of localization resources has been re-introduced. Related resources would be updated every 12 hours in order to provide better experience for non-Simplified-Chinese users.
- The configuration option `Loading Thread Count` has been removed. Now it always takes 4 threads.
- New configuration option `Minimal Gil Navigation` has been introduced. All the navigation across zones would take the most economical route, which means it would reduce the gil cost as much as possible by introducing probably a considerable amount of free transportation and zone connections. The navigation result could be unbearably lengthy.
- New Wine environment detection has been introduced, which would prevent the tray widget from being initialized and return a null value for TID & MID.
- An issue that it may be unable to teleport to an apartment or a shared estate in some cases has been fixed.
- The logic of resource cleaning has been improved.
- An issue that the module list couldn't be displayed in the main interface if no module has been enabled has been fixed.

## New Modules

### Striking Tree Helper [Duty]

*Recommended Module*

Automatically mark the party member with the status "	Terror" in the duty "Striking Tree (Hard)" for better perception.

### Fashion Accessory Command [Assistance]

*Recommended Module*

Provide a command /pdr {0} <action ID/action name/action name in pinyin> (partial inclusive and case insensitive) to execute a Fashion Accessory action.

### Auto Block Fire Or Blizzard [Action]

Automatically block the action "Blizzard" during the status "Astral Fire" and the action "Fire" during the status "Umbral Ice" in order to prevent misclicking if the current job is "Black Mage".

## Module Modifications

### Auto Highlight Status Action [Action]

- An issue that entries already edited couldn't be edited again has been fixed.
- An issue that the interface may flash while deleting an entry has been fixed.
- An issue of unexpected frequent storage during editing has been fixed.
- An issue that information of last combat would be valid for the next has been fixed.
- An issue that switching target may result in invalid highlighting has been fixed.
- Now unavailable actions at the time would not be highlighted.
- The appearance of the configuration interface has been optimized.
- The overall performance has been improved.

### Auto Retainer Work [Interface]

- The feature`Auto Half Retainer Gils` has been adjusted.
    - An issue that the feature didn't work on French and German clients has been fixed.
    - The mode option has been removed. New smart planning has been introduced and would run automatically while halving gils.
    - Various notifications have been introduced.
- `Auto Adjust Price After Collection` has been introduced for `Auto Collect Retainers`. Disabled by default.

### Auto FATE [Script]

- An issue of navigation anomalies in `Kholusia` due to the vast difference in terrain elevation has been fixed.
- Now the distance is considered a bit less while determining the next FATE.
- Some mode names have been adjusted.
    - `Multi-zone (for FATE Completion)` → `FATE Completion`
    - `Preferred & Alternative (for Gemstones)` → `Gemstones`
- New mode `Item` has been introduced. The module will automatically farm FATEs in one of the preset zones in order to collect specified items. After collecting all the items available in the zone, the character would navigate to another. The process will be repeated until all the specified items have been collected.
    - Pre-made presets:
        - Relic Weapon Atma
        - Anima Weapon
        - Resistance Weapon +1
        - Resistance Weapon Law's Order +1
        - Phantom Weapon
- Now the disability period of the character HP check has been extended from 2.5 seconds up to 15 seconds, since it takes quite some time to regenerate HP after finishing a low-level FATE.
- An issue that the character may frequently teleport to aetherytes in the mode `FATE Completion` has been fixed.
- Now any decision regarding the next step would be made 3 seconds later after finishing last FATE, in order to better simulate behaviours of a normal player and make reasonable decisions for consecutive FATEs.
- The behaviours while approaching enemies during non-collection FATEs have been improved.

### Set Time And Weather As Wish [Interface]

- An issue that disabling the module may result in broken unmanaged memory has been fixed.

### Glamour Plate Switching Commands [Assistance]

- An issue that the commands won't work if the glamour plate interface hasn't been accessed once after Patch 7.5 has been fixed.

### Better Enmity List [Interface]
