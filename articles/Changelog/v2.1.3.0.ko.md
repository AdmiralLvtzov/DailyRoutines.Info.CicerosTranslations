## 본체 변경

- 최초 지역 간 순간 이동 시 게임이 끊기는 문제를 수정
- 로드/언로드 과정의 스레드 컨텍스트 동기화 설계를 최적화
- 모듈 로드/언로드 중 발생한 예외가 비관리 계층으로 유출될 가능성이 있던 문제를 수정
- 로컬라이즈 리소스 온라인 동기 다운로드 기능을 재추가 (12시간마다 트리거, 비중국어 간체 사용자 경험 최적화)
- 설정 항목 `로드 스레드 수`를 제거, 이제 로드/언로드 모듈은 항상 4스레드로 동작
- 설정 항목 `최소 길 소모로 지역 간 이동` 추가, 활성화 시 플러그인 내부의 지역 간 이동 기능 사용 시 선착장 또는 지역 경계 도보 이동 등을 통해 최소한의 길을 소모하도록 시도 (매우 긴 경로가 발생할 수 있음, 기본값 비활성화)
- Wine 환경 감지 추가, Wine에서 트레이 알림 컴포넌트 초기화를 자동 차단, 장치 인증 증명서 (TID)와 PC 식별 인증서 (MID)는 자동으로 빈 값을 반환
- 아파트 및 공유 주택으로 순간 이동할 수 없던 문제를 수정
- 리소스 정리 로직 최적화
- 모듈이 하나도 활성화되지 않은 상태에서 메인 화면에 모듈 목록이 표시되지 않던 문제를 수정

## 신규 모듈

### "진 라무 토벌전" 도우미 [콘텐츠]

*추천 모듈*

인스턴스 던전 "진 라무 토벌전" 입장 후, "공포" 상태 이상에 걸린 파티원을 자동으로 마킹하여 신속한 해제를 지원합니다

### 패션 소품 기술 사용 명령어 [도우미]

*추천 모듈*

/pdr oac <기술 ID / 기술명 / 기술명 병음> (부분 일치, 대소문자 구분 안 함) 명령어를 추가하여 패션 소품 기술을 빠르게 사용할 수 있습니다

### "파이어"와 "블리자드" 시전 자동 차단 [액션]

현재 직업이 "흑마도사"인 경우, "천상의 화염" 상태에서 "블리자드" 사용과 "저승의 냉기" 상태에서 "파이어" 사용을 자동으로 금지하여, 실수로 천상의 화염 및 저승의 냉기 상태가 해제되는 것을 방지합니다

## 모듈 변경

### 상태 관련 기술 자동 강조 [액션]

- 편집한 항목을 수정할 수 없었던 문제를 수정
- 삭제 시 화면이 끊기는 문제를 수정
- 편집 시 디스크 저장 빈도가 너무 높았던 문제를 수정
- 기술 사용 정보가 전투를 넘어 저장되던 문제를 수정
- 대상 전환 후 다시 원래 대상으로 돌아오면 기술 강조 정보가 사라지던 문제를 수정
- 기술 사용 가능 여부 확인 추가, 기술을 실제로 사용할 수 없을 때는 강조 표시하지 않음
- 설정 화면 외관 스타일 최적화
- 모듈 전반의 성능 최적화

### 집사 수행 자동화 [인터페이스]

- `집사 길 자동 균등화` 기능 조정
    - 독일어 및 프랑스어 클라이언트에서 작동하지 않던 문제를 수정
    - 방법 선택 제거, 내부에서 지능적으로 균등 분배 경로를 계획하여 길 초과 방지
    - 각종 알림 메시지 추가
- `집사 수행 아이템 회수`에 설정 항목 `수령 후 자동 가격 조정` 추가, 기본값 비활성화
- 각 기능이 한국어, 프랑스어, 독일어, 중국어 번체 클라이언트 지원

### 자동 돌발 임무 [스크립트]

- 콜루시아 섬 상반부 지역의 일부 돌발 임무에서 고저차로 인해 경로 탐색 판단에 이상이 발생하던 문제를 수정
- 돌발 임무 선정에서 거리 가중치를 낮춤
- 모드 이름 변경
    - `다중 지역 (달성도)` → `돌발 임무 달성도`
    - `주/부 지역 (두빛깔 보석)` → `두빛깔 보석`
- 신규 모드 `아이템` 추가, 선택한 프리셋 지역 내에서 돌발 임무를 순회 완료하여 지정 아이템 수집, 해당 지역 내 모든 아이템 수량이 목표에 도달하면 다음 지역으로 이동, 설정한 모든 아이템 수집 완료 시까지 반복
    - 내장 프리셋
        - 고대의 무기: 아트마
        - 아니마 웨폰
        - 레지스탕스 웨폰 +1
        - 레지스탕스 웨폰: 법령+1
        - 팬텀 웨폰
- 돌발 임무 완료 시 낮은 HP 감지 일시 중지 시간을 2.5초에서 15초로 연장 (구버전 돌발 임무에 더 잘 대응)
- `돌발 임무 달성도` 모드에서 에테라이트로 반복 텔레포되던 문제를 수정
- 돌발 임무 완료 시 3초 대기 후 다음 판단을 수행 (연속 발생 가능한 돌발 임무 및 일반 플레이어 행동에 더 적합)
- 비수집형 돌발 임무 범위 진입 시 몬스터에 접근하는 동작 최적화

### 빠른 날씨 및 시간 설정 [인터페이스]

- 언로드 시 비관리 계층 메모리가 손상되던 문제를 수정
