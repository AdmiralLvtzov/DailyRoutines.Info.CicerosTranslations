## 本体修改

- 修复了首次使用跨区域传送逻辑时会导致游戏卡顿的问题
- 优化了加载卸载流程中整体线程上下文同步设计
- 修复了加载卸载模块时发生的异常可能泄露至非托管层的问题
- 重新加入了本地化资源在线拉取下载功能, 每 12 小时触发一次, 以优化非简体中文用户体验
- 移除了配置项 `加载线程数`, 现在加载卸载模块始终使用四线程
- 新增配置项 `以最少金币花费完成跨区域移动`, 启用后, 在调用插件内部的逻辑完成跨区域移动时, 会尝试以最低金币花费完成, 譬如通过船头、过图线等, 可能会产生极长的路径, 默认禁用

## 新增模块

### "拉姆歼灭战" 助手

*推荐模块*

进入副本 "拉姆歼灭战" 后, 自动标记带有 "恐怖" 状态的小队成员, 以帮助快速解除

### 时尚配饰技能使用指令

*推荐模块*

添加 /pdr oac <技能 ID / 技能名称 / 技能名称拼音> (部分包含, 大小写不敏感) 指令, 以快捷使用时尚配饰技能

## 模块修改

### 自动高亮状态效果对应技能 [技能]

- 修复了无法修改已编辑条目的问题
- 修复了删除时界面闪帧的问题
- 修复了编辑时落盘保存频率触发过高的问题
- 修复了技能使用信息会跨战斗保存的问题
- 修复了切换目标后再切回会导致技能高亮信息丢失的问题
- 新增技能可用性检查, 当技能实际不可用时不再高亮
- 优化了配置界面外观样式
- 优化了模块整体性能表现

### 自动雇员作业 [界面]

- 调整了 `自动平均雇员金币` 功能
    - 修复了无法作用于德语与法语客户端的问题
    - 移除了方法选择, 现在内部会智能规划平分操作路径, 避免金币溢出
    - 新增了各类通知消息
- 为 `自动收取雇员` 新增配置项 `收取后自动改价`, 默认禁用

### 自动临危受命 [脚本]

- 修复了在 `珂露西亚岛` 上半部分区域内的部分危命任务会因高低差过大导致寻路判断出现异常的问题
- 在危命任务选优中降低了距离的权重
- 调整了模式的名称
    - `多区域 (完成度)` → `危命任务完成度`
    - `主副区域 (双色宝石)` → `双色宝石`
- 新增模式 `物品`, 该模式下, 会在选定的预设区域内循环完成危命任务以收集指定物品, 当某区域内所有物品数量达标后前往下一个区域, 直至设定的全部物品收集完成
    - 内置预设
        - 上古武器·魂晶
        - 元灵武器
        - 义军武器+1
        - 义军武器·裁决+1
        - 幻境武器
- 完成危命任务时, 暂停低体力值检测的时间窗口从 2.5 秒延长至 15 秒, 以更好适应旧版本的危命任务
- 修复了 `危命任务完成度` 模式下可能反复传送至以太之光的问题
- 完成危命任务时, 会等待 3 秒再进行下一步决策, 以契合可能连续刷新的危命任务, 并更加契合普通玩家行为
- 优化了进入非收集类危命任务范围后接近危命任务怪物的行为表现

### 快捷天气时间设置 [界面]

- 修复了卸载时会导致非托管层内存损坏的问题

### 投影模板切换指令 [辅助]

- 修复了 7.5 后在未曾打开一次投影模板界面时, 无法使用指令切换投影模板的问题
