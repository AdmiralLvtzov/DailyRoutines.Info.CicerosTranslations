## Framework Modifications

- The bulit-in TTS has been removed. The feature has been migrated to an independent plugin named EdgeTTS.Dalamud.
    - The command `/pdr tts` is scheduled to be deprecated upon the release of the major update Evercold (8.0). Please consider continuing with EdgeTTS.Dalamud.
- The logic of instant movement has been improved.
- An issue that, aethernet shards for estates were not excluded when the character is visiting another world, has been fixed.
- An issue that, released resources may be accessed while reloading Daily Routines in some rare cases, has been fixed.

## New Modules

### Phantom Job Switching Command [Assistance]

*Recommended Module*

Provide a command /pdr {0} <ID / name (case insensitive, partial inclusive)> to switch to the specified phantom job in Occult Crescent.

### Better Phantom Job Repertoire [Duty]

*Recommended Module*

Replace "Phantom Job Repertoire" in Occult Crescent with a module interface using vanilla assets for better access, including custom order, explicit job names, immutable actions, unlock requirements, etc.

### Explicit Instance ID For Field Operations [Duty]

*Recommended Module*

Provide the instance ID in Server Info Bar and send a notification indicating the instance ID while joining a Field Operation duty.

### Auto Revival Farm [Script]

Automatically farm for revival achievements. One will pull high-level enemies as much as possible, the other will revive the puller after the puller dies. The module requires two players simultaneously and proper configurations before running it.

## Module Modifications

### Auto Read Dialogue Aloud [Interface]

- An issue that irrelevant speech tasks may be aborted in some rare cases has been fixed.

### Auto Login [System]

- An issue that it may attempt to login to characters visiting another data center in some rare cases has been fixed.

### Auto Count Players Nearby [General]

- Now player count statistics are more accurate in both large settlements and non-instanced areas.
- The floating window "Nearby Players" has been adjusted.
    - The scaling of job icons in the "Players Nearby" tab has been improved.
    - New "Players In Current Zone" tab has been introduced, which would be available in zones where acquiring the player count is viable.

### Custom Map Mark [Interface]

- An issue of deferred resource cleanup has been fixed.
- An issue that the two buttons within the in-game map didn't scale automatically according to the map size has been fixed.

### Auto FATE [Script]

- Now all the must-have prerequisite modules should be enabled before running the module.
- A cooldown lock has been introduced after completing a FATE in order to prevent getting stuck.
- The overall efficiency and performance have been improved.
- An issue that an unattended FATE would prevent the character from navigating to another zone has been fixed.
- Idempotency mechanism has been introduced for a various amount of operations for better reliability.
- Now FATEs requires manual initialization have been assigned the same weight as other FATEs.
- Now it would lean more towards engaging more enemies simultaneously based on distances and HP for better efficiency if the FATE progress is below 80%.
- An issue that the flow may get stuck if the data related to FATE rewards arrives earlier in some rare cases has been fixed.
- Now it would prioritize enemies with lower HP for better efficiency if the FATE progress is greater than or equal to 80%.
- All the internal processes have been converted to state machines in order to prevent process coupling among various subsystems.
- The configuration option `Distance To Teleport` has been removed.
- Now it would no longer actively engage `Forlorn` in any case.
- Now it would send a chat message indicating the time taken after completing a FATE for evaluation purposes.

### Field Operation Entry Command [Assistance]

- Now `Occult Crescent: North Horn` is supported, with a new parameter `ocn`.

### Occult Crescent Helper [Duty]

- Now it supports `Occult Crescent: North Horn`.
- Now `Auto Phantom Action For Durable Buff` supports `Phantom Freelancer`'s `Inquiring Mind`.
- The notification appearance has been adjusted.
- The texts in some interface have been adjusted.
- The configuration appearance has been adjusted.
- All the logic of instant movement has been removed. Now the module would perform wayfinding only. The wayfinding logic has been fully refactored.
- New feature `Auto "Offensive Aria"`, to automatically execute "Offensive Aria" if the character is not holding the status or the remaining time of the status is less than 20 seconds.
- The feature `Phantom Job Switching Command` is now an independent dedicated module. The command remains for compatibility purposes.
- The feature `Better Phantom Job Repertoire` is now an independent dedicated module. 
- The feature related to instance ID has been enhanced. Now it's an independent dedicated module named `Explicit Instance ID For Field Operations`.
- Two treasure routes in `South Horn` have been integrated.
- The visual appeal while farming for treasures has been improved.
- Now the process of treasure farming will be terminated if the character has left the duty or the user disconnects.

### Auto Confirm In Duty [Duty]

- The logic has been refactored, adopting an improved approach based on whitelist.

### Auto Sort Items [System]

### Auto Earth's Reply [Action]
