## 본체 변경

- 내장 TTS 기능을 제거하고 별도의 EdgeTTS.Dalamud 플러그인으로 변경
    - 게임 8.0에서 `/pdr tts` 기능을 제거할 예정입니다. 필요하다면 EdgeTTS.Dalamud 플러그인의 IPC를 연동하거나 해당 플러그인의 명령어를 사용하세요
- 플러그인 내부 텔레포트 로직을 최적화
- 크로스 월드 이동 후 자택 에테라이트가 제외되지 않던 문제를 수정
- 일부 상황에서 플러그인 리로드 시 해제된 리소스에 접근할 수 있던 문제를 수정

## 신규 모듈

### 서포트 직업 전환 명령어 [도우미]

*추천 모듈*

"초승달 섬" 내에서 지정된 보조 직업으로 빠르게 전환할 수 있는 /pdr pjob <ID (대소문자 / 구분 부분 없음, 이름 일치)> 명령어를 추가합니다.

### 개선된 서포트 직업 목록 [콘텐츠]

*추천 모듈*

초승달 섬의 "서포트 직업 목록" 창을 더욱 깔끔하고 사용하기 편리한 모듈 네이티브 UI로 대체합니다. 사용자 지정 정렬, 직업명 표시, 실제 스킬 끌어다 놓기, 해금 방법 표시 등의 기능을 지원합니다

### 특수 필드 탐색 인스턴스 ID 자동 표시 [콘텐츠]

*추천 모듈*

특수 필드 탐색에 진입할 때 서버 정보 표시줄에 현재 인스턴스 ID를 자동으로 표시하고, 채팅 메시지로 알림을 보냅니다.

### *자동 상호 부활* [스크립트]

양쪽 모두 설정을 마치면 한 명이 자동으로 고레벨 몬스터의 어그로를 끌어 빠르게 전투 불능 상태가 되고, 다른 한 명이 그 플레이어를 자동으로 부활시켜 관련 업적 진행도를 빠르게 쌓습니다.

## 모듈 변경

### 대화 자동 읽기 [인터페이스]

- 다른 음성 합성 및 읽어주기 작업을 잘못 취소하던 문제를 수정

### 자동 로그인 [시스템]

- 다른 데이터센터에서 플레이 중인 캐릭터에 로그인을 시도하던 문제를 수정

### 주변 플레이어 자동 표시 [일반]

- 필드, 마을 등의 지역에서 현재 인스턴스 인원을 표시할 수 있게 되었습니다
- "주변 플레이어 목록" 플로팅 창 내용을 조정
    - "주변 플레이어" 페이지의 직업 아이콘 렌더링 크기를 최적화
    - "현재 지역 플레이어" 페이지를 추가하여 인스턴스 인원을 지원하는 지역에서 표시

### 사용자 지정 지도 표식 [인터페이스]

- 일부 리소스 정리가 지연되던 문제를 수정
- 지도 화면 내 두 버튼이 지도 화면 너비 변화에 따라 위치를 조정하지 않던 문제를 수정

### 자동 돌발 임무 [스크립트]

- 필수 선행 모듈이 활성화되어 있는지 감지하는 기능을 추가
- 돌발 임무 완료 시 쿨다운 잠금을 추가하여 너무 빨리 전투 중으로 판정되지 않도록 함
- 전반적인 실행 효율과 성능을 개선
- 참여하지 않은 돌발 임무 정산 과정에서도 로컬 플레이어의 지역 이동을 막던 문제를 수정
- 많은 작업에 멱등성 보호를 적용
- 수동으로 시작해야 하는 돌발 임무의 가중치를 낮추는 로직을 제거
- 돌발 임무 진행도가 80% 미만이면 거리와 자신의 체력에 따라 몬스터를 더 끌어모아 완료 효율을 높임
- 일부 상황에서 돌발 임무 보상이 돌발 임무 데이터가 메모리에서 사라지기 전에 나타나면 흐름이 멈추던 문제를 수정
- 돌발 임무 진행도가 80% 이상이면 체력이 가장 낮은 몬스터를 첫 번째 우선순위로 삼아 더 빠르게 완료
- 내부 흐름을 모두 상태 머신으로 변경하여 서로 다른 시스템 간 흐름 결합 문제를 근본적으로 방지
- 설정 항목 `자동 텔레포트 거리`를 제거
- `희망 잃은 자`를 능동 공격하는 로직을 모두 제거
- 돌발 임무 완료 시 소요 시간을 채팅 메시지로 출력하여 효율 평가를 돕습니다

### 특수 던전 탐색 진입 명령어 [도우미]

- 진입 가능한 시나리오 `초승달 섬: 북부편` 추가, 파라미터 `ocn`

### '초승달 섬' 도우미 [콘텐츠]

- `초승달 섬: 북부편`에 대응
- `서포트 직업의 지속 시간이 긴 버프 스킬을 자동으로 사용합니다.` 기능이 `서포트 자유직`의 `탐구심` 기술을 자동으로 사용합니다
- 알림 메시지의 외형 스타일을 조정
- 일부 화면 텍스트 내용을 조정
- 설정 화면의 외형 스타일을 조정
- 모든 텔레포트 로직을 제거하고 길찾기로 변경했으며 길찾기 로직을 완전히 재구성
- `"공격의 노래" 자동 사용` 추가. 활성화하면 `공격의 노래` 상태 효과의 남은 시간이 20초 미만일 때 자동으로 사용을 시도합니다
- `서포트 직업 전환 명령어`를 제거하고 새 `서포트 직업 전환 명령어` 모듈로 이전. 명령어는 하위 호환성을 위해 그대로 유지
- 사용자 지정 `서포트 직업 목록` 화면을 제거하고 새 `개선된 서포트 직업 목록` 모듈로 이전
- `인스턴스 ID` 관련 기능을 제거하고 새 `특수 필드 탐색 인스턴스 ID 자동 표시` 모듈로 이전
- `남부편`의 두 보물찾기 루트를 통합
- 자동 보물찾기 과정의 동작을 자연스럽게 개선
- 자동 보물찾기 중 접속이 끊기거나 던전에서 나가면 자동 보물찾기가 자동으로 중지됩니다

### 컨텐츠 상호 작용 자동 확인 [콘텐츠]

- 모듈 로직을 재구성하고 더 정확한 화이트리스트 방식을 채택

### 아이템 자동 정리 [시스템]

- 새 지역에 진입하면 2초를 기다린 후 아이템 정리를 시작

### 【몽크】 금강전륜 자동 사용 [액션]

- 탈것에 탑승한 상태에서도 사용을 시도하던 문제를 수정

### 자동 아이템 분해 [인터페이스]

- 버튼 위치가 어긋나던 문제를 수정

### 전장 플레이어 레이더 [콘텐츠]

- 시야 밖에 있는 플레이어를 화면 가장자리에 표시

### 주변 플레이어 자동 표시 [인터페이스]

- 시야 밖에 있는 플레이어를 화면 가장자리에 표시
- 연결선의 외형 스타일을 조정

### 채팅 자동 응답 [일반]

- 일부 상황에서 메인 스레드가 아닌 곳에서 게임 함수에 접근해 게임이 크래시되던 문제를 수정

### '얼어붙은 영혼' 자동 사용 [액션]

- `블리자쟈`를 해금하지 않았을 때도 `얼어붙은 마음`을 3단계까지 회복하려 반복하던 문제를 수정
- 직업 전환 후에도 `얼어붙은 영혼`을 계속 사용하려 반복하던 문제를 수정
