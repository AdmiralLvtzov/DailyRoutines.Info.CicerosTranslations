## 本体修改

- 移除了内置的 TTS 功能, 改为单独的 EdgeTTS.Dalamud 插件
    - 预计将在游戏 8.0 版本移除 `/pdr tts` 功能, 如有需要, 请对接 EdgeTTS.Dalamud 插件的 IPC 或使用该插件的命令
- 优化了插件内部的瞬移逻辑
- 修正了跨服后房屋以太之光没有被排除的问题

## 新增模块

### 辅助职业切换指令 [辅助]

*推荐模块*

添加 /pdr pjob <ID / 名称 (大小写不敏感, 部分包含)> 指令, 以在蜃景幻界新月岛内快捷切换至内指定的辅助职业

### 更好的辅助职业列表 [副本]

*推荐模块*

将蜃景幻界新月岛中的“辅助职业列表”界面替换为更加美观易用的模块原生界面，支持自定义排序、外显职业名称、拖出真实技能、显示解锁方式等

### 自动显示特殊场景探索副本 ID [副本]

*推荐模块*

进入特殊场景探索副本时, 自动在服务器信息栏显示当前所在的副本 ID, 并发送聊天消息提醒

### 自动互刷复活 [脚本]

双人均配置完成后，一人自动引战高等级怪物尽快进入无法战斗状态，一人自动复活另一人，以快速累计相关成就进度

## 模块修改

### 自动朗读对话 [界面]

- 修复了会误取消其他语音合成与朗读任务的问题

### 自动登录 [系统]

- 修复了会尝试登录正在其他大区游玩的角色的问题

### 自动显示周边玩家数量 [一般]

- 支持在野外、城镇等区域显示当前区域人数
- 调整了“周边玩家列表”悬浮窗内容
    - 优化了“周边玩家”分页中职业图标的渲染尺寸
    - 新增了“区域玩家”分页，将在支持获取区域人数的区域渲染

### 自定义地图标记 [界面]

- 修复了部分资源清理不及时的问题
- 修正了地图界面内的两个按钮未跟随地图界面宽度变化而修改位置的问题

### 自动临危受命 [脚本]

- 新增前置模块启用检测, 将检测必须使用的前置模块是否已被开启
- 为危命任务完成时加入冷却锁, 避免过快被判定为卡在战斗中
- 提升了整体运行效率与性能表现
- 修复了未参加的危命任务结算过程中仍然会阻止本地玩家切换区域的问题
- 将大量操作都做了幂等保护
- 移除了降低需要手动开始的危命任务权重的逻辑
- 现在会在危命任务进度低于 80% 时, 自动根据距离、自身体力尝试拉取更多的怪物以提升完成效率
- 修复了若危命任务奖励部分情况下先于危命任务数据消失在内存前出现则流程卡死的问题
- 现在当危命任务进度 ≥ 80% 时, 会自动将体力最低的怪物放置于第一优先级, 以求更快完成
- 内部流程全部改为状态机, 以从根源上避免不同系统的流程耦合问题
- 移除了配置项 `自动传送距离`
- 移除了任何主动攻击 `迷失者` 的逻辑
- 危命任务完成时, 将以聊天消息形式输出用时, 以帮助评估效率

### 特殊场景进入指令 [辅助]

- 新增可进入场景 `蜃景幻界新月岛 北征之章`, 参数 `ocn`

### 蜃景幻界新月岛助手 [副本]

- 适配了 `蜃景幻界新月岛：北征之章`
- `自动使用各辅助职业的长效增益效果技能` 功能将自动使用 `辅助自由人` 的 `探求心` 技能
- 调整了通知消息的外观样式
- 调整了部分界面文本的内容
- 调整了配置界面的外观样式
- 移除了所有瞬移逻辑, 均改为寻路, 且完全重构了寻路逻辑
- 新增 `自动使用“攻击之歌”`, 启用后会在 `攻击之歌` 状态效果剩余不足 20 秒时自动尝试插入使用
- 移除了 `辅助职业切换指令`, 迁移至新的 `辅助职业切换指令` 模块, 命令保持不变以向后兼容
- 移除了自定义的 `辅助职业列表` 界面, 迁移至新的 `更好的辅助职业列表` 模块
- 移除了 `岛 ID` 相关功能, 迁移至新的 `自动显示特殊场景探索副本 ID` 模块
- 合并了 `南征之章` 的两条寻宝路线

### 自动确认副本内物体对话框 [副本]

- 重构了模块逻辑, 采取了更加精确的白名单模式

### 自动整理物品 [系统]

- 进入新区域后, 会先等待两秒再开始整理物品

### 自动使用金刚转轮 [技能]

- 修复了在坐骑上仍会尝试使用的问题

### 自动道具分解 [界面]

- 修复了按钮错位的问题

### 纷争前线玩家雷达 [副本]

- 现在会在屏幕边缘显示在视野之外的玩家

### 自动显示周边玩家数量 [界面]

- 现在会在屏幕边缘显示在视野之外的玩家
- 调整了连线的外观样式
